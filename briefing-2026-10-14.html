  • Claude Code v2.1.299, October 14 — new. ✅ Idle compaction: a conversation of 200,000 or more tokens left idle for about 54 minutes is compacted before its one-hour prompt cache expires; the threshold is set with CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS and the feature can be turned off with "idleCompaction": false. New CLAUDE_CODE_DISABLE_FILE_MENTIONS variable sends file paths rather than contents for @ mentions. UserPromptSubmit hooks now run before a skill or custom command expands, so a blocking hook also stops its embedded shell commands. The exit resume line uses the session ID rather than the session name. Also added: /effort and /fast in agent view, --shutdown-drain-sec for the self-hosted runner orchestrator, and --disallow-tools for claude plugin eval (Claude Code changelog). ✅ MCP changes: connector and Anthropic-hosted MCP requests no longer follow HTTP redirects; cloud and Remote Control connectors negotiate MCP protocol version 2026-07-28 by default, with MCP_PROTOCOL_NEGOTIATION=legacy to opt out; allow rules now match only the named server, so mcp__a no longer covers a server named a__b. ⚠️ We read the first 100,000 of about 124,586 characters of the page.
