3. Agentic AI Advances & New Releases

  • Claude Code v2.1.288, October 2 (changelog, read through automated page summarization). ✅ Added $.ui.selection() for mods to return selected text and transcript row in fullscreen mode; added a built-in gh api to cloud sessions without the GitHub CLI; added recovery for prompts cleared with Ctrl+C; added a re-authentication prompt when MCP servers request additional OAuth scope; added a --max-findings <n>|all flag to /code-review; added Ctrl+F to find sessions by name. Fixes include mid-response API timeouts in non-interactive sessions and subagents, long conversations failing with "Prompt is too long" through auto-compacting, resumed sessions sometimes not saving the last response, and auto-mode denials pointing to incorrect Bash permission rules. 🔶 The summary we read lists these as notable changes and may not be exhaustive.
  • OpenAI — October 2 builder's guide for the GPT-6 family (primary, read through automated page summarization). ✅ Four recommendations: run efficiently in production with caching and compaction, match the model to the workload on capability, cost and latency, tune prompts and skills for clarity about deliverables and boundaries, and keep long-running tasks moving with steering, async tools and delegation; the guide quotes OpenAI's Eric Provencher: "Models have gotten much better at understanding nuance and ambiguity, so overly specific guidance can now hinder results where it previously helped." ⚠️ The newsroom listing titles the post "A practical guide to building with GPT-6," while our page summary headed it "A Model Guide for the GPT-6 Family"; we could not reconcile the two, and the pricing above is the guide's own, vendor-reported.
