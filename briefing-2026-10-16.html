3. Agentic AI Advances & New Releases

  • Claude Code v2.1.301, October 15 — new. ✅ MCP: fixed an issue where sessions started from Slack on a self-hosted runner could not find or attach a repository when managed settings restrict MCP servers; the entry points to deniedMcpServers for keeping those tools off. Hooks: a mod hook's .catch handler now runs only when the hook throws or times out; quitting no longer removes a worktree made by a WorktreeCreate hook without asking when it may hold unpushed commits; artifact updates that were refused where a PreToolUse hook covers Edit or Write now edit the file and then republish; the permission prompt for a plugin or skill hook's ask decision now shows where the hook came from. Permissions: added CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS so unattended retry mode ends a request at a usage limit that resets too far away; added classifier_verdict, permission_mode and classifier_category fields to OpenTelemetry tool_decision events.
