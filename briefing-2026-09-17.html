What This Means for You. Two items, and both are policy work rather than tooling work. ✅ The first is the ${VAR} secret-disclosure fix in v2.1.274: MCP connection errors and the login tool's own description were showing secrets resolved from placeholders in MCP configs. Any organization whose staff have been pasting error output into a ticket, a chat thread or a support case has a plausible credential-exposure path that closed this morning and was open before it — which makes credential rotation, not just upgrading, the correct remediation to specify. ⚠️ That is a compliance-awareness action item with something concrete to do in it, not a note to file. The second is enduser.sub in gateway telemetry. A documented AI implementation policy should treat any new identifier appearing in a telemetry stream as a reportable change to the organization's data map, and this one — an identity-provider subject, stable across systems — is exactly the category a data-protection impact assessment asks about. ✅ Neither item is a defect to complain about; both are the kind of change that only shows up if someone reads the changelog line by line, which is the argument for having someone do it. 🔶

What This Means for You. The Google Home MCP server is the item to brief your organization on, and not for the reason it will be covered. ✅ The setup path is the finding: a consumer creates a Google Cloud project, configures an MCP server, hands the configuration to an agent, and grants OAuth permissions to reach a home camera archive. That is an enterprise integration pattern being handed to a consumer, and the same pattern is what your staff will now recognise and attempt at work. ⚠️ The practical consequence is that shadow-MCP — employees connecting personal or unsanctioned agents to organisational data through a protocol their IT team may not yet inventory — moves from a hypothetical to something with a mainstream on-ramp this week. The policy work that follows is narrow and writable today: an MCP server register, a rule that OAuth grants to agents are provisioned centrally rather than by end users, and a statement of which categories of data an agent may be granted. ✅ It pairs directly with the CrowdStrike Falcon Guardian shadow-agent discovery capability announced September 1, which gives the control a tooling answer as well as a policy one. 🔶
